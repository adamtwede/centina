# Quickstart

## What to do first

Centina is a lot easier to understand by using it than by reading about it, and its value is a lot easier to see that way too. So once it's [installed](/install-claude-code), open a coding agent session in the project you want to build and invoke the `centina-session-zero` skill:

```text
/centina-session-zero
```

Then describe what you want to build, in a sentence or two of plain prose. The first time you run it, it'll ask where your project root is and where Centina's own files should live (`./centina/` by default). After that, it walks you through each gated phase, one at a time, and ends by handing you a skeleton spec set and an `ARCHITECTURE.md`.

Going through one session will teach you more than reading the rest of this documentation. Once you've got a firsthand sense of how it works, come back here for a deeper understanding of how to get the most out of it. [How to actually use it](/using-it#how-to-actually-use-it) is a good place to start.
